# Tripana Implementation Plans (`docs/plans/`)

This folder holds versioned Markdown implementation plans generated by the [`tripana-plan`](../../.agents/skills/tripana-plan/SKILL.md) skill and executed by [`tripana-build`](../../.agents/skills/tripana-build/SKILL.md) and [`tripana-review`](../../.agents/skills/tripana-review/SKILL.md).

## Naming Convention

`YYYY-MM-DD-<feature-or-page-slug>.md`

## Lifecycle Statuses

1. `Draft (Awaiting User Approval)` — Created by `tripana-plan` after the interactive alignment interview (`ask_question`).
2. `Approved / In Progress` — Updated by `tripana-build` once the user approves the plan.
3. `Built (Ready for Review)` — Updated by `tripana-build` after all checklist items and local verification checks pass.
4. `Completed & Verified` — Finalized by `tripana-review` after auditing the git diff against the plan and `design.md`.
